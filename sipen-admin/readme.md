# ADMIN

### Sistema de Controle de Usuários

O projeto é desenvolvido utilizando a linguagem PHP com o framework Laravel

Utiliza o banco de dados PostgreSQL e a mesma base de dados do AVA (Moodle)

## Dependências
* [git](https://git-scm.com/book/pt-br/v1/)
* [Composer](https://getcomposer.org)
* [PHP >=5.6.4](http://php.net)
* [Extensão php-mcrypt](http://pt.stackoverflow.com/a/1712)
* [Mbstring PHP Extension](http://askubuntu.com/questions/764782/install-laravel-5-on-ubuntu-16-04)
* [PHP-DOM Extension](https://laracasts.com/discuss/channels/servers/how-do-i-install-the-dom-extension-for-php7)
* [PostgreSQL](http://www.postgresql.org/)
* [Laravel 5.4](http://laravel.com/docs/5.3)


## Git Tags
[Git-Essencial-Tagging](https://git-scm.com/book/pt-br/v1/Git-Essencial-Tagging)

Para criar uma tag (versão) utilize, por exemplo, o comando abaixo:

`git tag -a v1.20 -m 'conteúdo/change log desta versão'`

Assim, é adicionada a tag "v1.20" com referência ao commit atual.
outra forma git tag "v.1.20"

Para enviar essa tag criada para o repositório (compartilhá-la), utilize por exemplo:

`git push origin v1.20`ou git push --tags
